# GAS 中継のデプロイ手順

Bot（サービスアカウント）は Google ドライブに「新しいファイル」を作れません（保存容量が無いため）。
そこで、**あなたの Google アカウントで動く小さなウェブアプリ**（この中継）に、新規作成・改名・ゴミ箱への移動だけを頼みます。
詳しい設計は `SPEC.md` の §2.5 にあります。

この中継ができること: `06-Life-OS/` の中でのファイル新規作成、画像の作成、改名、ゴミ箱へ移動。
できないこと: 読み取り、既存ファイルの上書き、`06-Life-OS/` の外への操作、フォルダの改名・削除。

## 準備するもの

- 中継用の秘密の文字列（トークン）。`life-os-bot/.env` の `GAS_RELAY_TOKEN` に、すでに自動で入っています（手順 3 で使います）
- `06-Life-OS` フォルダの ID: `.env` の `OBSIDIAN_LIFEOS_FOLDER_ID` と同じ値です

## 手順

### 1. プロジェクトを作る
1. <https://script.google.com> を開き、**Obsidian のフォルダを持っているあなたの Google アカウント**でログインします
2. 「新しいプロジェクト」を押し、名前を `life-os-relay` などに変えます

### 2. コードを貼る
1. 左の「エディタ」で `コード.gs`（`Code.gs`）を開き、中身をすべて消して、このフォルダの `Code.gs` の内容を貼り付けます
2. 左の歯車「プロジェクトの設定」→「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェックを入れます
3. エディタに戻り、`appsscript.json` を開いて、このフォルダの `appsscript.json` の内容に置き換えます
4. 保存します（Ctrl+S）

### 3. 設定値（スクリプト プロパティ）を入れる
1. 歯車「プロジェクトの設定」→ 下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
2. 次の2つを追加して保存します

| プロパティ | 値 |
|---|---|
| `RELAY_TOKEN` | `life-os-bot/.env` の `GAS_RELAY_TOKEN=` の右側の文字列をコピー（前後に空白を入れない） |
| `LIFEOS_FOLDER_ID` | `.env` の `OBSIDIAN_LIFEOS_FOLDER_ID=` の右側の値 |

### 4. 権限を承認する（最初の1回だけ）
1. エディタ上部の関数選択で `authorize` を選び、「実行」を押します
2. 「承認が必要です」→「権限を確認」→ アカウントを選びます
3. 「このアプリは Google で確認されていません」と出たら、「詳細」→「life-os-relay（安全ではないページ）に移動」→「許可」
   （自分で作ったスクリプトなので問題ありません。この承認は取り消さない限り有効で、7日で切れることはありません）
4. 実行ログに `OK: 06-Life-OS` と出れば成功です
5. 続けて `selfTest` を選んで実行し、ログに「selfTest: すべて成功」と出ることを確認します

### 5. ウェブアプリとして公開する
1. 右上「デプロイ」→「新しいデプロイ」→ 歯車から「ウェブアプリ」を選びます
2. 次のとおりに設定して「デプロイ」を押します

| 項目 | 設定 |
|---|---|
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **全員**（Bot は Google にログインせずに呼ぶため必要です。トークンが合わない依頼は実行されません） |

3. 表示された「ウェブアプリ」の URL（`https://script.google.com/macros/s/…/exec`）をコピーします
4. `life-os-bot/.env` の `GAS_RELAY_URL=` の右側に貼り付けます

### 6. 動作確認
```
.venv/Scripts/python scripts/verify_relay.py
```
12 項目がすべて OK になれば完了です（検証用ファイルは自動でゴミ箱に移ります）。

## 運用のメモ

- **コードを直したとき**: 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン: 新バージョン」→「デプロイ」。こうすると URL が変わりません（「新しいデプロイ」だと URL が変わります）
- **トークンを変えたいとき**: 新しいトークンを作り、スクリプト プロパティの `RELAY_TOKEN` と `.env` の `GAS_RELAY_TOKEN` の**両方**を更新します。作り方: `.venv/Scripts/python -c "import secrets; print(secrets.token_urlsafe(32))"`
- **中継を止めたいとき**: スクリプト プロパティの `RELAY_TOKEN` を削除（または別の値に変更）すれば、その瞬間からすべての依頼が拒否されます
- **実行履歴の確認**: Apps Script の左メニュー「実行数」で、いつ何が呼ばれたかを確認できます
- URL とトークンは他人に教えないでください（URL だけ知られても、トークンが無ければ何も実行されません）
