## 0. 目的と大事にすること

- 目的: フリーランスのクリエイター（小説・シナリオ・TRPG など、テキストの仕事）として、自分のペースで独立する。ストック型の収入を作る。
- 今いちばん欲しいもの: 7割で止まっている作品を、完成（出品）まで持っていける仕組み。
- 大事にすること（これまでの方針）: 責めない・急かさない・「1文字でも進んだら100点」。
- 避けたいこと: 頭がパンクする量の情報を一度に出すこと。

- 運用の流れ（2026-10-15 決定）: **プロジェクトを決める → タスクに落とし込む → 日々のスケジュールにする**

```
作品管理の表（プロジェクト・3本まで）
   ↓ 工程を小さく分ける（Bot が案を出し、自分が選ぶ）
タスク（01-today-task・タスク棚）
   ↓ 日曜日に次の週の分を考える（その都度、直してよい）
今週の予定 → 今日の3つ（朝の案内・今日の一覧）
```

## 1. スケジュール管理（1日・1週の流れ）

| 決めること | 状態 | 答え |
|---|---|---|
| 1-1. 作業しやすい時間帯 | ✅ | **深夜・日によってバラバラ**（→ 1-2・2-5 の日付の区切りが大事になる） |
| 1-2. 1日の区切り（何時で「次の日」にするか。今は日記だけ朝5時） | ✅ | **朝5時**。日記だけでなく、完了日・やったこと・今日の一覧も全部これに揃える |
| 1-3. 休みの日の扱い（決まった曜日／気分で） | ✅ | **両方**: ①**土日はバッファの日**。週の計画では、できるかぎりタスクを割り振らない（終わらなかった分の受け皿にする）。ただし土日にしかできない作業もあるので、入れることもできる（柔軟に）。②「今日は休む」と書いた日は、その日のタスクの移し先を番号で選ぶだけ。責めない |
| 1-6. タスク → 予定への落とし込み | ✅ | **日曜日に次の週のタスクを一度考え、その都度直していく** |
| 1-7. 週の計画の始め方 | ✅ | **自分が「来週の計画」と書いたとき**に始める（日曜に書かなければ、月曜の朝に一言だけ声をかける） |
| 1-8. 週の中での分け方 | ✅ | **リストを作って曜日ごとに割り振る。ただし変えていく前提**（気軽に入れ替え・先送りできること） |
| 1-9. 割り振った日に終わらなかったタスク | ✅ | **そのつど、どこに移すか自分で決める**（Bot は勝手に動かさず、候補を番号で示して選ぶだけにする。例: 明日／別の曜日／来週／作品の棚に戻す） |
| 1-4. Bot から話しかける時間と回数（今は朝8時・夜23時など） | ✅ | **今のまま**（朝8時の案内・10時の執筆実績・夜23時の振り返り） |
| 1-5. 締切に持たせる余裕（調子の波の見込み方） | ✅ | **2週間以上の余裕**。締切ごとに3つの日付を持つ: ①**本当のデッドライン** ②その**1週間前 = 予定日** ③その**2週間前 = 自分の目標日**。タスクの割り振りは③に向けて組み、①②は「まだ余裕がある」ことを見せるために使う |
