## 次にやること（この順に）

### 1. push する（コードは済み）

コードは push 済み。この引き継ぎメモ（`docs/NEXT_STEPS.md`）と `CLAUDE.md` の更新も残したいときは、PowerShell で:

```powershell
git status
git add -A
git commit -m "引き継ぎメモを更新"
git push
```

`.env` `credentials.json` `data/` `deploy/vm.env` は `.gitignore` で除外済み（`git status` に出ていないことを確認してから `git add -A`）。

### 2. VM を更新する（済んでいなければ）

1. パソコンの Bot が動いていないことを確認する（動いていると、VM 側は終了コード 3 で止まる）。
2. Google Cloud コンソール →「Compute Engine」→「VM インスタンス」→ `life-os-bot` の **SSH** ボタン。
3. 黒い画面で: `cd ~/life-os-bot && bash deploy/update.sh`（`git pull`・ライブラリの更新・Bot の再起動）。`active (running)` と出れば成功。
4. 問題があれば: `sudo journalctl -u life-os-bot -n 100 --no-pager`。詳細は `docs/DEPLOY.md`。

`.env` の追加は不要（`WRITING_TIME` は既定が 10:00）。

## 設計上の判断（私が仮定で決めたもの。違っていたら伝える）

詳細は `SPEC.md` §5 の各チャンネルの「仮定」と §10。

- **共通**: 相談・検索の質問そのものは、ノートに追記しない。1 投稿の URL は 3 件まで、危険な URL は保存せず拒否。X（Twitter）は第三者サービス fxtwitter 経由。作品名がない初回は `未命名_日付` で作り、後で改名。
- **05-private**: 迷ったとき・添付つきの投稿は、問い合わせではなくメモとして保存。画像も保存する。
- **06-household-accounts**: 「今月の娯楽費はいくら？」の問い合わせには対応しない（返信は、投稿したときの累計だけ）。
- **07-ledger**: 売上か経費か決められない行は、推測せず聞き返す。転記を取り消す操作はない（シートで直接外す）。レシート画像は証憑として保存する。
- **04-report**: 週は月曜始まり。「先月比」は数字の事実として載せる（評価はしない）。天気の傾向は「雨」だけ。
- **取扱マニュアル**: 週次・月次レポートの度に自動更新し、前の版を `Health-Manual-前回.md` に 1 世代残す。
- **14-ai**: タスクの削除は Obsidian で行う（シートの行だけ消すと、同期で戻るため）。方針（13）は、13 の部屋への投稿だけで変える（14-ai・シート・ノートの文章からは変えられない）。会話の記憶は 3 往復・30 分。変更は確認なしで即実行するが、量の上限（変更 10 件・削除 5 件）と、操作ログ・取り消しで守る。シートを直しても、対応するノートは変わらない。
- **昨日の執筆実績**: 朝 8:00 の案内には載せず、別の投稿にする（当日の行が 09:44 に記録されるため。以前は「二日前」の実績を「昨日」と表示していた不具合を修正）。
